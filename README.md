# VivaanFWD Final Portfolio

## Structure

```text
vivaanfwd-final/
├── index.html
├── css/
│   └── style.css
└── js/
    └── app.js
```

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server.

## Deploy to Render

Create a Static Site and set the publish directory to the folder containing `index.html`.

## Before publishing

Replace:
- `your-email@example.com`
- `https://github.com/`
- `https://www.linkedin.com/`

The current profile visual is intentionally a CSS/Bootstrap placeholder, so the page does not depend on a missing image file.
